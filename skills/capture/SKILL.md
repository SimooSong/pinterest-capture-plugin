# Skill: Pinterest Capture Agent

## 역할

이 서브에이전트는 Search Agent가 수집한 이미지 URL 목록을 받아, 각 이미지를 스크린샷으로 캡처하고 로컬에 저장합니다. 저장 전 미리보기를 제공하고 중복을 방지합니다.

## 입력

Search Agent가 반환한 JSON 데이터:

```json
{
  "keyword": "[검색 키워드]",
  "collected_count": 30,
  "image_list": [...],
  "save_path": "C:\\Projects\\my-project\\captures\\[키워드_날짜]"
}
```

## 실행 지침

### 1단계: 저장 폴더 준비

```
1. SAVE_PATH 폴더 존재 여부 확인
2. 없으면 생성: mkdir -p [SAVE_PATH]
3. 폴더명 형식: [키워드_YYYYMMDD_HHMMSS]
   예: minimal_interior_20240315_143022
```

### 2단계: 미리보기 목록 출력

캡처 시작 전 수집된 이미지 목록을 사용자에게 표시합니다:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📌 Pinterest 캡처 미리보기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
키워드: [keyword]
수집 수: [collected_count]장
저장 경로: [save_path]

[이미지 목록 - 번호, PIN URL 표시]
 1. https://pinterest.com/pin/...
 2. https://pinterest.com/pin/...
 ...
30. https://pinterest.com/pin/...

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
위 30개 이미지를 캡처하여 저장할까요?
[Y] 저장 진행  [N] 취소  [번호] 특정 항목 제외
```

사용자 확인을 받은 후 다음 단계로 진행합니다.

### 3단계: 이미지 캡처 및 저장

사용자가 확인(Y)하면 순서대로 캡처를 실행합니다:

```
각 이미지에 대해:
1. Playwright MCP로 이미지 URL 직접 접속
   browser_navigate → [image_url]
2. 전체 페이지 스크린샷 캡처
   browser_take_screenshot → full page
3. 파일명 생성:
   [keyword]_[순번3자리]_[url_hash].png
   예: minimal_interior_001_a3f9b2c1.png
4. SAVE_PATH에 저장
5. 진행률 표시: [5/30] 캡처 완료...
```

### 4단계: 중복 방지 최종 검사

각 파일 저장 전 확인:

```
1. 동일 파일명 존재 여부 확인 → 있으면 건너뜀
2. url_hash 기반 기존 파일 검색 → 동일 해시면 건너뜀
3. 건너뛴 경우 로그에 기록
```

### 5단계: 완료 보고

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ 캡처 완료
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
키워드: [keyword]
저장됨: [저장 수]장
건너뜀 (중복): [중복 수]장
저장 경로: [save_path]

저장된 파일:
 - [keyword]_001_[hash].png
 - [keyword]_002_[hash].png
 ...
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 파일명 규칙

```
[keyword_snake_case]_[순번 3자리]_[url_hash 8자리].png

예시:
minimal_interior_001_a3f9b2c1.png
minimal_interior_002_7d4e1f82.png
카페_브랜딩_001_c8a2d093.png
```

- keyword: 공백을 언더스코어로 변환, 특수문자 제거
- 순번: 001~030 (3자리 zero-padding)
- url_hash: 이미지 URL의 MD5 해시 앞 8자리

## 오류 처리

- 이미지 로딩 실패 (404, 타임아웃): 해당 이미지 건너뛰고 계속 진행
- 디스크 쓰기 오류: 오류 메시지 출력 후 중단, 저장된 파일은 유지
- 캡처 실패 3회 연속: 사용자에게 알림 후 계속 여부 확인
- 사용자가 N 선택: 수집된 데이터 폐기, 저장 경로 미생성

## 주의사항

- 저장 전 반드시 사용자 확인 단계를 거침 (미리보기 필수)
- 중복 체크는 파일명과 해시 두 가지 방법으로 수행
- 캡처 중 사용자가 취소하면 이미 저장된 파일은 유지
- 이미지당 최대 15초 대기 후 실패 처리
